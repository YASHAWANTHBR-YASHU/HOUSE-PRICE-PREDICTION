# 🏠 House Price Prediction App

This project is a Machine Learning-based web application that predicts house prices based on various features such as square footage, number of bedrooms, location quality, and more.

The application is built using **Python, Scikit-learn, and Streamlit**, providing an interactive and user-friendly interface.

---

## 🚀 Features

- 🏡 Predict house prices instantly
- 📊 Interactive input interface
- 🎯 Accurate regression model
- 💻 Simple and clean UI using Streamlit
- 📦 Pre-trained model using `.pkl` file

---

## 🧠 Machine Learning

- Regression model trained on housing dataset
- Uses features like:
  - Square Footage
  - Number of Bedrooms & Bathrooms
  - Year Built
  - Lot Size
  - Garage Size
  - Neighborhood Quality
